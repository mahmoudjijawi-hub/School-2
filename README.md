# نظام المعاهد - نسخة تجريبية (Demo)

نسخة تجريبية عربية لنظام إدارة معاهد تعليمية، مبنية بـ Django وقوالب HTML عادية.
الهدف عرضها على العميل بسرعة وليس نشر إنتاجي كامل.

## المتطلبات

- Python 3.10+
- pip

## التشغيل المحلي

```bash
# 1. استنساخ المشروع
git clone <repo-url>
cd maahid

# 2. إنشاء بيئة افتراضية (اختياري)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 3. تثبيت المتطلبات
pip install -r requirements.txt

# 4. إعداد متغيرات البيئة
cp .env.example .env
# عدّل SECRET_KEY و DEBUG حسب الحاجة

# 5. تطبيق الهجرات وزرع البيانات التجريبية
python manage.py migrate
python manage.py seed_demo

# 6. تشغيل السيرفر
python manage.py runserver
```

افتح المتصفح على: http://127.0.0.1:8000/

## بيانات الدخول التجريبية

| الدور | الرقم المميز | بيانات إضافية |
|-------|-------------|---------------|
| مدير | `1001` | مستخدم: `admin` / كلمة المرور: `admin123` |
| أستاذ | `2001` | محمد العلي - رياضيات |
| أستاذ | `2002` | فاطمة السعيد - لغة عربية |
| أستاذ | `2003` | خالد الحربي - علوم |
| طالب | `3001` | عبدالله محمد |
| طالب | `3002` | نورة أحمد |
| طالب | `3003` | سعود خالد |
| طالب | `3004` | ريم سعد |
| طالب | `3005` | فيصل عمر |

> الأساتذة والطلاب يدخلون بالرقم المميز فقط (نسخة تجريبية).
> المدير يحتاج الرقم المميز ثم اسم المستخدم وكلمة المرور.

## النشر على Render

1. ارفع المشروع على GitHub
2. أنشئ **Web Service** جديد على [Render](https://render.com)
3. اختر المستودع واضبط:
   - **Build Command:** `./build.sh`
   - **Start Command:** `gunicorn maahid.wsgi --log-file -`
4. أضف متغيرات البيئة:
   - `SECRET_KEY` = مفتاح عشوائي طويل
   - `DEBUG` = `False`
   - `ALLOWED_HOSTS` = `your-app.onrender.com`
5. اضغط Deploy

> **تنبيه:** القرص على Render المجاني **غير دائم** — قد تُفقد بيانات SQLite عند إعادة التشغيل.
> أعد تشغيل `seed_demo` بعد كل نشر جديد إذا لزم الأمر.

## الفرق بين النسخة التجريبية والإنتاجية الكاملة

| الميزة | النسخة التجريبية (هذه) | النسخة الإنتاجية |
|--------|------------------------|------------------|
| قاعدة البيانات | SQLite | PostgreSQL |
| API | لا يوجد (Django Templates) | Django REST Framework + JWT |
| تعدد المعاهد | معهد واحد | Multi-tenancy |
| دخول الأستاذ/الطالب | بالرقم المميز فقط | مصادقة كاملة |
| الأمان | أساسي (CSRF, throttling بسيط) | 2FA, Audit log, rate limiting |
| الجلسات | جلسة واحدة بسيطة | تعدد أجهزة وجلسات |
| النشر | Render مجاني بسيط | بنية إنتاجية كاملة |

## الأدوار والصلاحيات

- **مدير:** إدارة كاملة (أساتذة، طلاب، برنامج، علامات، حضور، مدفوعات)
- **أستاذ:** قراءة بياناته وبرنامجه فقط
- **طالب:** قراءة بياناته فقط (الوصول عبر الجلسة، بدون ID في الرابط)
